# Proyecto 03 — Datos con Vida

**Meta:** Explorar datos reales de forma visual, sin que se sienta como estadística aburrida.

En este proyecto vas a cargar un archivo de datos y hacerle preguntas con código. Los gráficos serán tu herramienta principal.

## Dataset que usaremos

`shared/data/videojuegos.csv` — una tabla de 20 videojuegos populares con:
- título, género, año, horas promedio, calificación, plataforma

Es corto, fácil de entender y divertido.

---

## Al terminar este proyecto sabrás

- Cómo cargar un CSV con pandas.
- Cómo filtrar datos con condiciones.
- Cómo crear gráficos de barras, dispersión y líneas.
- Cómo conectar widgets con gráficos para exploración interactiva.
