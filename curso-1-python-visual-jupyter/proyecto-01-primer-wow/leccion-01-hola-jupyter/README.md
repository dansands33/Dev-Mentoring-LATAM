# Lección 01 — Hola Jupyter

## Objetivo

Abrir tu primer notebook, ejecutar celdas y ver que Python responde a lo que escribes.

## ¿Qué vas a construir?

Un notebook con mensajes personalizados y variables que guardan información.

## Conceptos nuevos

- **Celda:** un bloque de código o texto en Jupyter.
- **`print()`:** función para mostrar texto en pantalla.
- **Variable:** un nombre que guarda un valor.

## Pasos

1. Abre Jupyter y navega a esta carpeta.
2. Abre el archivo `hola_jupyter.ipynb`.
3. Ejecuta la primera celda con `Shift + Enter`.
4. Observa el resultado debajo de la celda.
5. Cambia el texto entre comillas y vuelve a ejecutar.
6. Sigue con cada celda en orden.

## ¿Qué debería pasar?

Verás mensajes en pantalla. Algunos dirán "Hola" seguido del nombre que pongas. Si cambias el nombre en el código, el mensaje cambia también.

## Mini reto

Cambia el mensaje para que diga tu nombre y tu carrera. Algo como:
```
Hola, soy Ana y estudio Ingeniería de Software.
```

## Errores comunes

| Error | Causa probable |
|---|---|
| `SyntaxError` | Falta una comilla o paréntesis. Revisa la línea marcada. |
| `NameError: name '...' is not defined` | Escribiste mal el nombre de una variable. |
| Las celdas no ejecutan | ¿Está el entorno activado? Reinicia Jupyter desde el venv. |
