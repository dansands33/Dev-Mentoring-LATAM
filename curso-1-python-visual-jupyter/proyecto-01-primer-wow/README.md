# Proyecto 01 — Primer Wow

**Meta:** Sentir que Python controla cosas visibles desde el minuto uno.

En este proyecto vas a descubrir que con pocas líneas de código puedes cambiar colores, textos y figuras en tiempo real. No necesitas saber mucho, solo seguir los pasos.

---

## Lecciones

| # | Lección | Qué construyes |
|---|---|---|
| 01 | [Hola Jupyter](leccion-01-hola-jupyter/) | Tu primer notebook funcionando |
| 02 | [Variables que cambian el mundo](leccion-02-variables-que-cambian-el-mundo/) | Variables que controlan lo que ves |
| 03 | [Sliders, botones y colores](leccion-03-sliders-botones-y-colores/) | Controles interactivos en tiempo real |
| 04 | [Mini reto: tablero interactivo](leccion-04-mini-reto-tablero-interactivo/) | Panel visual que responde a tus controles |

---

## Antes de empezar

1. Asegúrate de tener el entorno activado (ve a `docs/guia_instalacion_windows_mac.md`).
2. Abre Jupyter desde esta carpeta.
3. Lee el `README.md` de cada lección antes de abrir el notebook.

---

## Al terminar este proyecto sabrás

- Qué es un notebook y cómo ejecutar celdas.
- Qué es una variable y para qué sirve.
- Cómo usar sliders y botones para controlar tu código.
- Que programar puede ser inmediato y visual.
