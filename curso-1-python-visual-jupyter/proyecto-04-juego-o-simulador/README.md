# Proyecto 04 — Juego o Simulador

**Meta:** Cerrar el curso con energía, construyendo algo que funciona como un juego real.

En este proyecto vas a unir lógica (`if`/`else`), azar (`random`), puntaje y widgets para crear un juego funcional en tu notebook.

---

## Lecciones

| # | Lección | Qué construyes |
|---|---|---|
| 01 | [Lógica de juego](leccion-01-logica-de-juego/) | Condiciones y reglas con `if`/`else` |
| 02 | [Azar, puntaje y reglas](leccion-02-azar-puntaje-y-reglas/) | `random`, contador de puntaje, rondas |
| 03 | [Interfaz simple en notebook](leccion-03-interfaz-simple-en-notebook/) | Widgets para jugar: botones, estado, output |
| 04 | [Reto final: Piedra, Papel o Tijeras](leccion-04-reto-final/) | Juego completo con interfaz visual |

---

## Al terminar este proyecto sabrás

- Cómo usar `if`/`elif`/`else` para crear reglas.
- Cómo usar `random` para generar azar.
- Cómo mantener estado (puntaje, rondas) entre acciones del usuario.
- Cómo construir una interfaz mínima pero funcional en un notebook.
- Que puedes crear algo que otras personas pueden jugar.
