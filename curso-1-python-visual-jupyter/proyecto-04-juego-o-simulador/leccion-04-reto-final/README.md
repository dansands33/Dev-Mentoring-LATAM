# Lección 04 — Reto Final: Piedra, Papel o Tijeras

## Objetivo

Construir un juego completo de Piedra, Papel o Tijeras con interfaz visual en el notebook.

## ¿Qué vas a construir?

Un juego funcional donde el jugador elige su opción con botones, la máquina elige al azar, y el juego lleva el marcador.

## Conceptos usados

Todo lo del curso:
- Variables y f-strings
- `if`/`elif`/`else` para las reglas del juego
- `random.choice()` para la máquina
- Widgets: botones, labels, outputs
- Estado persistente entre clics
- Funciones para organizar el código

## Pasos

1. Abre `reto_final.ipynb`.
2. Lee el código antes de ejecutar.
3. Ejecuta todo y juega.
4. Completa el mini reto al final.

## ¿Qué debería pasar?

Tres botones: Piedra, Papel, Tijeras. Al hacer clic, la máquina elige al azar y se determina el ganador. El marcador se actualiza en tiempo real.

## Mini reto

Agrega:
1. Un historial de las últimas 5 jugadas.
2. Un botón "Ver estadísticas" que muestre cuántas veces elegiste cada opción.
