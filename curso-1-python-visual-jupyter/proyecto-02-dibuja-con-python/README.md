# Proyecto 02 — Dibuja con Python

**Meta:** Aprender bucles y funciones de forma visual, creando patrones y figuras con código.

En este proyecto vas a descubrir que los bucles no son teoría aburrida: son la herramienta para repetir un dibujo cien veces en una sola línea.

## Antes de empezar

Asegúrate de haber completado el Proyecto 01. Los conceptos de variables y ejecución de celdas se usan aquí.

---

## Al terminar este proyecto sabrás

- Cómo dibujar figuras simples con matplotlib.
- Qué es un bucle `for` y para qué sirve.
- Cómo definir una función y reutilizarla.
- Que el arte generativo es solo código repetido con variaciones.
