# Plan del Curso 1 — Python Visual con Jupyter

## Objetivo general

Que el estudiante pueda usar Python en Jupyter para:
- Crear variables, funciones, condicionales y bucles sin sentirse perdido.
- Ver resultados visuales inmediatos.
- Interactuar con su código usando widgets, sliders y botones.
- Hacer gráficos simples desde datos reales.
- Cerrar el curso con un mini juego o simulador funcional.

---

## Proyectos y lecciones

### Proyecto 01 — Primer Wow

**Meta:** El estudiante siente que Python controla cosas visibles desde el minuto uno.

| Lección | Título | Habilidades |
|---|---|---|
| 01 | Hola Jupyter | Abrir un notebook, ejecutar celdas, `print`, variables básicas |
| 02 | Variables que cambian el mundo | Variables numéricas y de texto, efectos visuales inmediatos |
| 03 | Sliders, botones y colores | `ipywidgets`: slider, botón, selector de color |
| 04 | Mini reto: tablero interactivo | Proyecto corto que une widgets con salida visual |

---

### Proyecto 02 — Dibuja con Python

**Meta:** Enseñar bucles y funciones a través de dibujos y patrones visuales.

| Lección | Título | Habilidades |
|---|---|---|
| 01 | Formas y colores | `matplotlib` básico: puntos, líneas, círculos |
| 02 | Patrones con bucles | `for`, posiciones, colores, tamaños |
| 03 | Funciones que dibujan | Definir funciones con parámetros, reutilizar código |
| 04 | Póster generativo | Mini proyecto: imagen generada por código |

---

### Proyecto 03 — Datos con Vida

**Meta:** Introducir análisis de datos de forma visual y sin intimidar.

| Lección | Título | Habilidades |
|---|---|---|
| 01 | Primer gráfico | Cargar CSV, ver columnas, graficar con `matplotlib` |
| 02 | Explora datos con filtros | Filtrar con `pandas`, responder preguntas simples |
| 03 | Gráficos con widgets | Cambiar gráfico según selección del usuario |
| 04 | Mini dashboard | Tabla resumen + gráfico + controles integrados |

---

### Proyecto 04 — Juego o Simulador

**Meta:** Unir lógica básica con interacción para cerrar el curso con energía.

| Lección | Título | Habilidades |
|---|---|---|
| 01 | Lógica de juego | `if`, comparaciones, reglas simples |
| 02 | Azar, puntaje y reglas | `random`, puntaje acumulado, repetir rondas |
| 03 | Interfaz simple en notebook | Widgets para jugar: botones, outputs, estado |
| 04 | Reto final | Mini juego completo: Piedra, Papel o Tijeras visual |

---

## Herramientas del curso

| Herramienta | Uso |
|---|---|
| `jupyter notebook` | Entorno principal de trabajo |
| `ipywidgets` | Sliders, botones, dropdowns interactivos |
| `matplotlib` | Gráficos y dibujos |
| `pandas` | Manejo de datos en tablas |
| `numpy` | Operaciones numéricas básicas |
| `random` | Generación de azar (incluido en Python) |

---

## Duración estimada

- Cada lección: 30–60 minutos.
- Cada proyecto: 2–4 horas.
- Curso completo: 8–16 horas de práctica real.

---

## Criterios de éxito por lección

- El estudiante puede ejecutar el notebook de inicio a fin sin errores.
- El estudiante puede explicar con sus palabras qué hace cada celda principal.
- El estudiante completa el mini reto al final de la lección.
